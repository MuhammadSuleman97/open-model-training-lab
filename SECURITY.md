# Security policy

This is an educational local-training project, not a production banking
service. Do not expose the example HTTP server to public interfaces or use its
predictions for financial decisions.

## Reporting a problem

For suspected credential exposure, unsafe deserialization, arbitrary file
access or another security issue, use GitHub's private vulnerability-reporting
feature when it is enabled. Do not include secrets or personal financial data
in a public issue.

## Supported version

Security fixes target the latest revision on the default branch.
