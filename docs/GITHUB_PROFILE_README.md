# Muhammad Suleman

I am learning open-model training in public, with an emphasis on reproducible
experiments, honest evaluation and understanding why systems fail.

## Featured project

### Open Model Training Lab

I trained Qwen, BERT and DeBERTa on BANKING77 using an Apple M2 Max:

- 15 controlled experiments;
- Qwen + MLX/LoRA from 47.86% to 51.10%;
- architecture pivot to encoder classification;
- DeBERTa at 92.99% validation and 94.12% reporting-only test accuracy;
- numerical failures diagnosed instead of hidden; and
- an interactive beginner course with glossary, quiz and interview practice.

[Explore the repository](https://github.com/msulemans/open-model-training-lab)
· [Open the learning guide](https://msulemans.github.io/open-model-training-lab/)

## Currently learning

- fine-tuning and evaluation of open-weight models;
- Apple Silicon ML with MLX and PyTorch MPS;
- dataset quality and leakage-safe experimentation; and
- turning technical investigations into useful public learning material.

## Principles

- Baseline before training.
- Validation chooses; test reports.
- A stable run can still disprove its hypothesis.
- Failed experiments belong in the documentation.
