# Experiments

This directory retains compact public Qwen/MLX run records. Training logs,
adapters and interrupted artifacts remain ignored.

The later BERT/DeBERTa checkpoints and trainer state live under the ignored
`artifacts/` tree because they are much larger. Their reproducible configs,
scripts, checksums and aggregate metrics remain public.

For a readable Exp001–015 narrative, use
[docs/EXPERIMENT_JOURNEY.md](../docs/EXPERIMENT_JOURNEY.md). For exact summary
metrics, use [docs/RESULTS.md](../docs/RESULTS.md).
